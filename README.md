# ศึกกระดาน

เกมวางแผนรบบนแผ่นดินสยาม เริ่มจากแม่ทัพตัวคนเดียว จ้างชาวบ้าน ปราบโจร ตีเมือง ยึดดินแดน

- `index.html` — ตัวเกมทั้งหมดในไฟล์เดียว เปิดเล่นในเบราว์เซอร์ได้เลย ไม่ต้องใช้เน็ต
- `android/` — แอป Android ที่ห่อตัวเกมไว้
- `src/` — โค้ดต้นฉบับ (game.js, fx.js, sfx.js, campaign2.html, build.py)

## ไฟล์ .apk
ทุกครั้งที่อัปโหลดโค้ดขึ้นสาขา `main` GitHub จะสร้างไฟล์ `sukkradan.apk` ให้อัตโนมัติ
ดาวน์โหลดได้ที่หน้า **Releases** ด้านขวาของหน้า repo นี้
